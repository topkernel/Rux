§2分层与 unsafe 治理

docs/architecture/kernel-layers.md 定义最长前缀匹配的分层:未匹配的文件默认落最安全桶。

  • Framework 层(arch/mm 原语/interrupt/virtio 核心/trace/perf):允许 unsafe,逐块要求 // SAFETY: 注释(覆盖 3,207/5,009 = 64%)。
  • service 层:目标 100% forbid(unsafe_code) —— 已 47 个文件编译期禁止,另 56 个已无 unsafe;首个具名收缩目标 syscall/io.rs 69 个 unsafe token 已清零(typed entries + uaccess_safe)。
  • syscall 边界 = 胶囊边界:入口统一校验并翻译用户指针;uaccess_safe.rs 提供类型化 copy_in/copy_out。
  • unsafe 行占比 12.9%;trace 模块整体禁 unsafe。

§3仓库顶层布局

Rux/
├── kernel/       # 内核源码(上表)

├── test/         # guest 侧 C 探针源码(pbench.c 等)+ 套件目录(ubuntu-gnome、ltpscan、stressng…)
├── scripts/      # 宿主侧:extract-probes.sh、test/(run.sh、run-x86-ub.sh、oh-boot.sh…)
├── toolchain/    # 自建 musl 交叉工具链(build-musl.sh、riscv64-rux-linux-musl/、x86_64 sysroot tarball)
├── build/        # 构建/配置工具(build/Makefile、menuconfig.sh、current-platform.sh)
├── work/         # 运行期产物(gnome-x86.img、rootfs、pbench 盘)
├── docs/         # 文档中心:guides/ architecture/ development/ test/ progress/
├── AGENTS.md     # 绑定性开发工作流(事实贡献指南)
├── Kernel.toml   # 内核配置 → kernel/src/config.rs
└── Makefile      # 顶层入口(转发 build/Makefile)
探针 tarball 政策:guest 测试用例源码只以 userspace/probes/probes.tar.gz + extract.sh 归档;make user/make test 经 scripts/extract-probes.sh 幂等恢复,仓库不跟踪散的 guest C 源文件。

§4语言构成

内核本体 100% Rust(no_std,除必要的平台汇编);用户态探针为 C(musl 交叉编译);仓库语言统计以 git ls-files 口径为准(vendored 的 toybox 标注 linguist-vendored)。
