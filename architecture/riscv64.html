架构移植指南

三架构的热路径设计:陷入、上下文切换、uaccess、中断控制器 · 出处 docs/architecture/riscv64.md / aarch64.md

§1riscv64:陷入路径

  • 来源检测:sscratch/tp 交换方案 —— 内核态 sscratch=0、tp=Task;用户态反之(早期 tp=hartid<0x1000 回退 sstatus.SPP 判定)。
  • PtRegs 288 字节 repr(C):x1–x31 顺序 + status/badaddr/cause/orig_a0(系统调用回滚)。
  • 内核陷入切 per-CPU 中断栈(16KB/CPU);用户陷入从 ti_kernel_sp(task+0x08)取内核栈。
  • 大锁协议:进入取内核大锁 amoswap.d.aq、退出 amoswap.d.rl;退出前 sc.d 清 LR/SC 预约(防跨上下文泄漏)+ fence iorw,iorw。
  • Task 字段硬编码偏移(flags 0x00 / preempt 0x04 / kernel_sp 0x08 / user_sp 0x10 / cpu 0x18 / state 0x20 / pid 0x24)。

上下文切换(参考序)

fpu_save_for_switch   # FS==DIRTY 才存 f0-f31+fcsr, 置 OFF
set_prev → switch_mm  # satp 前后各一次 sfence.vma(ASID=0 不嵌入)
__switch_to           # ra/sp/s0-s11/SUM, tp=next
restore_fpu           # fs != OFF 才使能

uaccess

  • SUM 位括号(Rust + 汇编双实现,返回未拷字节数);.ex_table 例外表 insn,fixup。
  • 三段拷贝:对齐字节 → 8× 展开 64B/迭代字拷带移位(阈值 WORD_COPY_MIN=71)→ 尾字节。

ASID / TLB / IPI

  • Sv39 9 位 ASID:0=内核、1=保留、2–511 用户;原子位图 CAS 分配,耗尽线性扫;flush 家族 all/asid/page/range/kernel。
  • IPI:0=重调度、1=停机,SSIP 接收。

§2x86_64:热路径三杠杆

  • FSGSBASE:rdfsbase/wrfsbase 替代 FS/GS MSR 对,实测 393 ns/切换。
  • 惰性 FPU:xsaveopt 移入 #NM 处理器(已验证内核二进制无编译器 FP)。
  • PCID:CPUID 门控使能,per-mm tag + invlpg shootdown(只在硬件报告该位的 CPU 上武装 —— "每 CPU 都武装"的 #GP 已修)。
  • 三杠杆合计:lat_ctx -s64 2 4.97→2.07 µs(−58%)。

x86_64 专项细节

  • SMAP(分歧 D-18):CR4.SMAP 使能;usercopy 用 pushfq/orq/popfq AC 括号而非 STAC/CLAC —— 后者在 QEMU TCG 下无条件 #UD(配对定罪);括号成本 ~55 ns;SMAP-VIOL 信标全 suite 零。
  • syscall 面:MSR 入口;SYSRET 适格性遇 TF|RF 回退 iret;EFLAGS.DF 脏入内核曾反转 rep movsb(已修);CR0.WP 自最早 boot 即设。
  • 用户态 W^X:NX 映射、PT_GNU_STACK、READ_IMPLIES_EXEC。

§3aarch64:移植要点

  • 每任务状态:TPIDR_EL0 就是任务 TLS 态(用户态直写,无 set-tls 系统调用;__switch_to 提交点保存/安装、fork 继承、exec 双清)—— 丢失它杀死了第一个 fork。
  • FPSIMD:预编译库的 NEON 会在系统调用中弄脏用户 FP —— EL0 向量陷入把活寄存器捕入 thread.user_fpsimd,eret 前重装;信号帧取自该缓冲。
  • SVC 语义差:SVC 后 ELR 指向之后一条(ecall 停在原处)—— 系统调用路径绝不前移 PC,ERESTARTSYS 回退 pc−=4。
  • GICv3:DS=1 下 GICD_CTLR bit1=Grp1NS;IGROUPR 在 0x0080;ICC_SGI1R 编码;虚拟定时器 PPI 11=INTID 27;PL011 RX 需武装 RX|接收超时双中断;解封两腿(GIC interface + PSTATE.DAIF.I)缺一不可。
  • 内存图:PAGE_OFFSET=0xffff_c000_0000_0000、TASK_SIZE=256GB(曾用 1TiB 常数把 mmap 基推出 walker 子树)、TCR_EL1.IPS=44 位(32 位默认时 ≥4GB 翻译取 address-size abort 而非 translation fault)。
  • ASID 修复:NEXT_ASID 单调不查在用表 → 254 个 mm 后永久 None 全量 flush;移植 riscv64 位图复用到 256 池。

当前边界(如实)

  • 1/9 boot flake(trap frame 恰过线性映射末端 —— 内核栈顶问题,排查中)。
  • LTP-on-aarch64 未开始(cross-build + serial-fed smoke 子集已奠基)。
  • dfx= 启动旗标不可用(EL2 跳板在 cmdline 解析前毁 DTB 指针),退回编译期 feature 门控。

§4移植新架构的检查单

  1. 启动协议与早期映射(memblock 前的页表页三阶段)。
  2. 陷入入口:来源检测、PtRegs、per-CPU 中断栈、大锁 aq/rl 对、LR/SC(或等价)清理。
  3. 上下文切换序(FPU 状态、地址空间切换 + TLB 注意事项)。
  4. uaccess(SUM/AC 类机制 + 例外表)。
  5. 中断控制器 + 时钟(Sstc/APIC 定时/GICv3 PPI)。
  6. per-CPU 区与 tp/TPIDR 类寄存器。
  7. 对接 INV-LOCK-7(per-mm PTE 锁)与 D-17(MMIO 竞技场,无恒等窗)。
