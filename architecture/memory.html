内存管理

从 memblock 到 vmemmap、buddy、small_alloc 与页缓存 · 出处 docs/architecture/memory.md + mm/ 源码

§1地址空间布局

虚拟内存布局常量与Linux逐项一致,保证用户态 ELF 加载器与 /proc 视图的兼容。以 Sv39(riscv64)为例:

区域地址 / 大小
线性映射 PAGE_OFFSET0xFFFFFFD600000000
vmalloc 区64 GB
vmemmap(页描述符)4 GB
内核链接基址0xFFFFFFFF80000000(物理 0x80200000)
TASK_SIZE(用户空间)256 GB
用户/内核 PGD 划分256 / 256 项

§2启动三段式

memblock → fixmap → zone/buddy:memblock 维护 memory + reserved 双区表(128 区上限);页表页经历三个阶段(BSS 静态 EARLY_PMD×8/EARLY_PTE×128 → memblock → zone)。分配器就位前后的世界被严格分开。

§3页描述符与 buddy

  • vmemmap:每个物理页一个 64 字节、cache 行对齐的 Page(flags/mapcount/refcount/private/mapping/index/type/next_free),pfn↔page 转换 O(1)。引用计数语义:fork 共享 +1,COW 写页 +2;put 到 0 才真正释放。
  • zone/buddy:MAX_ORDER=10(最大 4MB 块),free list 挂在 Page.next_free,释放按 buddy_pfn = pfn ^ (1<<order) 逐级合并;Unmovable/Movable/Reclaimable 三迁移类型。
  • PCP(per-CPU pageset):order-0 分配走 per-CPU 快路径,零 zone 锁;high/batch 水位成批回补。
  • kswapd / OOM:WMARK_HIGH 唤醒,连续失败 16 次触发 OOM killer;LRU 双链 + referenced 旋转 + rmap + 压缩(双指针扫描 + 页迁移)配套齐备。

§4内核堆三级

kmalloc
  ├─ ≤1024 B  → small_alloc(SLUB 式小对象打包层)
  ├─ 8..4096  → slab.rs 十级(独立路径)
  └─ >4 KB    → buddy(0–20 阶 standalone)

small_alloc:magazine 缓存层

  • 8 个 2 幂类(8..1024B);slab 页 16 字节页头(magic 0x5142),FIRST_OFF(S)=max(16,S) 保证对象对齐。
  • per-CPU magazine(深 16):分配/释放走 magazine,类锁只在成批 refill/flush 时取一次 —— 这是"类锁分段 ≤25M/次启动"门禁行的来源(实测 19.7M,最新板 6.0M)。
  • free 位图路由 + tripwire:每 slab 页一比特路由;清位先于还页 —— 陈旧指针落到 buddy 的 哨兵上,而不是静默破坏。
  • 锁序:类锁 → buddy 锁。
  • 起源:OH 首帧 ~21.3 万个 1B–1KB 净活对象(23.2M allocs/23.0M frees),每对象独占一个 4KiB buddy 块 = 852MB/992MB 窗口 —— 分配器在首帧合成阶段耗尽,magazine 为此而生。

打包内核栈 slab(分歧 D-2,x86_64)

三个内核栈打包进一个 256KB order-6 块(80KB 槽)+ 旁表槽映射 + 空块回收:每栈 85.3KB vs 128KB(栈占 42% 的 904MB 底盘省 ~115MB),99.9% 槽打包,史上最深 3445 活任务零 canary 命中。未门控的架构编译期剔除(80KB 余量是 x86_64 实测数)。

§5页缓存

  • 键:((fs_id, inode), page_index) —— 无 fs_id 会跨文件系统串页。
  • 锁模型(pcache Option-B):全局 slot 表无锁读(reader bank SeqCst RMW + Acquire 槽探测)+ 每 inode 自旋锁;wlock 只管插入/驱逐;整槽移除走 tombstone + 等 bank 排空再 drop。
  • 容量:下限 8192 页(32MB),软上限 = 受管 RAM 的一半。旧固定 32MB 上限曾使 OH 大库加载每缺页 ~1.5s(SA:3002 OpenSo 802166ms)。
  • 窗口批填充(分歧 D-12):一次往返填整个 miss 窗(需求区 + 顺序预读窗,或 16 页 fault-around 簇);物理连续段合并为单多块请求(bio::bread_async_multi,≤64 块/128KiB);一致性守卫在首个已缓存块处切断 run(防 DMA 绕过活脏 buffer)。

§6延迟与并发控制

  • 延迟释放环(D-16):MmStruct/Task 释放进全局 16384 项环,1500 ms 墙钟到期排水 —— 回收延迟有界且与调度活动无关(QSBR RCU 看不见 procfs 走访者的未记账借用,故用墙钟)。
  • per-mm PTE 锁(INV-LOCK-7,三架构统一):全局 epoch(RwSpinlock 读)+ 每 mm 自旋的 split 模式,取代原全局 PTE 锁(后者曾让 fork-walk 独占全机 CPU)。
  • 叶子表直走 unmap:所有权使每页 walker 无分配;每 2MiB 块解析一次上链、直接迭代叶 PTE。实测:mmap 平均 72 µs→27–32 µs(max 749 ms→2.1–3 ms)、munmap 体 177–185→52 µs、>16MiB mmap 中位 5.6 ms→415–427 µs;OH 负载 vm-op 族 ~15 s→~5 s/CPU-min。
  • 匿名页回收(SP-7):回收检查率 35%→82–89%,swap 写 +75%。

§7缺页路径

FaultFlags(READ/WRITE/EXEC/USER/KERNEL)
内核态: 栈溢出 → panic | exception table fixup | 否则 KernelPanic
用户态: VMA 查找 → 权限检查 → 栈扩展(GROWSDOWN)
        → 匿名页: 零页分配
        → COW: PTE bit 8 软件标志; refcount==1 直接翻 W, >1 复制
        → 越界: SIGSEGV / SIGKILL 分发

§8历史教训(bug 分类学摘录)

  • buddy split 未标已分配 → 同一块双发(016b3fa1)。
  • vmscan refcount<=0 下溢臂双自由;page_cache 双失效页双 put(f4b67f66,R14-16)—— "typed Refcount" 缺口的两个实例。
  • CpuLocal 首版落非 mut static → LLVM 置 .rodata → opt≥1 全部存储被删除(15.9M 对象/2 次锁持有的灾难性静默),UnsafeCell 再落地后反汇编验证。
  • copy_kernel_mappings 复制指向用户 L0 的内核 L1 项 → execve 覆写父进程 PTE(7a497838)。
  • munmap 分块重构曾丢尾批 TLB flush(c4a548d7 修复;OH 电池数小时内抓到,合成探针因读回同陈旧态而结构性失明)。
