§2运行时长与桌面会话门

  • GNOME 全会话 2100 秒门(M1–M5 里程碑全过,零 panic)三次独立启动复现(2026-10-27)。
  • 桌面会话保持 45 分钟零 panic(GDM 端到端链路,2026-11-01);boot-to-login ~4.5 s(4 vCPU MTTCG)。
  • GUI 验证器(test/ubuntu-gui/verify.py):每次启动 23 项像素/串口检查;键入式终端对话两次独立启动逐像素一致(convcheck)。
  • OH 侧:bootanimation → SystemUI 锁屏 → 135+ 服务集,舰队猴测持续走查(见压力子页)。

§3自愈观测(census + heal)

  • 每任务逐字段 tick 观测 + 幻影 preempt-count 判定(200 连续 tick,合法括号是微秒级)+ 20 ms 饥饿界 + softirq 分派延迟门。
  • 实测:64.5k/52.1k 次 heal 共 605 ms,model-vs-reality MISS=0;IF=0 占机 25.7% → 20.4%;最长关中断段 594–599 ms 一次性 → 6–9 ms;WAKE-STRANDED 233 → 31。
  • 每次合格静默 boot 的 census 精确一致(TERM-DESCHED 8、WAKE-REFUSED 32)—— 稳定性本身是带门禁的常设指标。

§4裁决纪律

  • 抖动隔离:新失败隔离复跑 2× 再定性(宿主负载超时/精度抖动族:accept02、getrusage04、kill02、genfmod、rename/statfs);性能门同规则(先重跑一次再定回归)。
  • NOT-OURS 台账:同一二进制跑宿主 Linux 内核对照,一致的失败记为测试/环境问题。
  • 仪器误诊归档:PTGUARD/FREEGUARD 误判(mapcount=−1 是 PAGE_MAPCOUNT_BIAS 哨兵)、首版 PT_LEDGER 假双自由 + 真帧泄漏、GRQ race 理论错误 —— 带收据的阴性结果留在记录里。
  • panic 面设计化:每处 panic 实例收编 + 回归测试消除(UTF-8 打印族、负备忘 null-deref、mmprof 槽命名空间等十余条收据)—— 详见安全栏目 §6。
