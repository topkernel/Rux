路线图与里程碑

启动验证时间线 + 当前目标 · 权威源:docs/progress/roadmap.md

§1当前目标(2026-11)

  • 完整 GNOME 桌面闭环(x86_64 + KVM 主平台):GDM 登录已达成, gnome-session 组件链(gsd → gnome-shell)收尾中。
  • OpenHarmony launcher → 桌面:/data 挂载与 SystemUI 锁屏已达成,继续向完整 launcher 主屏推进。
  • LTP 通过率最大化:r27 = 1084/1869,持续清 FAIL/CRASH/TIMEOUT 面。
  • 调试手段对齐Linux 内核:tracepoint 框架扩张中(lock/tcp/input 族 + PSI + 日志控制);深水区 lockdep/RCU-stall/blktrace/perf-probes/kdump。

§2里程碑时间线

2026-09-29

Ubuntu 22.04(riscv64)完整用户态启动

图形桌面会话(framebuffer + evdev)、bash -i、D-Bus 双总线、pty、SysV IPC、4-CPU SMP。

2026-10-07

x86_64 平台并入 main

Ubuntu 22.04 amd64 在 q35 启动到图形桌面;同期 LTP x86 r3 = 850/1869。

2026-10-14

GNOME Shell 桌面上屏

gnome-shell/mutter + Xorg-fbdev:活动栏、时钟、工作区缩略图、dash;2100 秒零 panic。

2026-10-24

OpenHarmony 开机动画上屏

bootanimation → render_service → 合成 → 扫出,整条 OH 图形链路在 Rux 上跑通。

2026-10-27

GNOME Shell 完整成帧 + 输入闭环

三次独立启动复现、零 panic;virtio-input IRQ 化,键入字符在焦点终端回显。

2026-10-28

键入式 shell 对话逐像素验证

两次独立启动,convcheck 判定行几何与光标格逐像素一致。

2026-10-30

aarch64 并入 main

QEMU virt(cortex-a72)交互 root shell、信号、套件 1119/1119 绿;必须 -M virt,gic-version=3。

2026-10-31

OpenHarmony /data 挂载 + SystemUI 锁屏渲染

ext4 superblock 32 位校验修复后原装 userdata 挂载成功;StartUser(100) 64 ms;锁屏全要素渲染(时钟/日期/状态栏/解锁提示)。

2026-11-01

GDM 登录问候界面(x86_64 + KVM)

原装链路端到端:udevd → logind(CreateSession 真 session fd)→ gdm3 → PAM → gdm-x-session → gnome-session;45 分钟零 panic;boot-to-login ~4.5 s。同日起 x86_64+KVM 为标准测试机位;fs 元数据族重锚定(−65%~−88%)。

2026-11-05/06

LTP r27 = 1084/1869;mm-unmap churn-race 家族关闭

PI futex 全量入 main;munmap 分批 TLB flush 竞态家族(bug 分类学第 34 行)关闭并回移植三架构。

  • aarch64 LTP 起步;btrfs 支持评估。
