命令速查表

以根 Makefile 为准

§1make 目标

目标说明
make build构建内核(默认 riscv64;PLATFORM=x86_64 / aarch64 切换)
make runQEMU 启动最小 rootfs(mrsh,/bin/sh)
make ubuntu-run构建 + SDL 窗口启动 Ubuntu GNOME 桌面(KVM,root/rux)
make test内核内测试套件(可 PLATFORM= 切架构)
make rootfs制作最小根文件系统镜像(依赖 user+toybox+mrsh)
make user / toybox / mrsh / sdk用户态程序 / 200+ 工具箱 / POSIX shell / musl SDK
make ltp构建 LTP 测试套件(需 sdk)
make verify / kani / spin / miri形式验证四层
make config / menuconfig查看 / 交互配置内核(Kernel.toml)
make debugGDB 调试内核
make bin / info / clean生成二进制 / 项目信息 / 清理

§2调试命令

# panic 地址符号化
riscv64-linux-gnu-addr2line -e <kernel> -f -C <addr>

# 离线提取 guest 日志(debugfs, 拷贝出的镜像)
debugfs -R "cat /var/log/kmsg" rootfs-copy.img

# 死锁/挂死捕获(自动构建带持有者信息的内核 + 压力用例注入 + 现场抓取)
./test/hunt-wedge.sh [rounds]

# tracefs(统一 tracepoint)
mount -t tracefs none /sys/kernel/tracing
echo 1 > /sys/kernel/tracing/events/sched/sched_wakeup/enable
cat /sys/kernel/tracing/trace

# kmsg 环形缓冲
dmesg            # guest 内
dmesg -n 7       # 重开全量控制台日志

§4操作纪律

  • 共享镜像启动一律 -snapshot + file.locking=off。
  • 只杀自己启动的 QEMU;测试默认 -smp 2 -m 1G。
  • 标准流程不手写 QEMU 命令(参数都在 Makefile / 驱动脚本里)。
  • 提交信息英文;主仓库根不落临时文件(放自己工作树的 run/)。
