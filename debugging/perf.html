性能调试

perf_event_open 系统调用面、syscost 启动普查、pbench 微基准、IF=0 探针与性能门禁 —— 每件工具的设计、数据形状与使用协议 · 依据:kernel/src/perf/、kernel/src/dfx/syscost.rs、test/pbench.c、docs/development/perf-gate-baseline.md

§1perf_event_open(系统调用 241)

Rux 实现参考内核的 perf_event_open ABI(asm-generic 编号 241),软件事件面:

  • 事件类型:CPU_CLOCK / TASK_CLOCK / PAGE_FAULTS / CONTEXT_SWITCHES;计数与采样双模式。
  • 采样模式:mmap 环输出记录,字段序 ID/IDENTIFIER/IP/TID/TIME/ID/STREAM_ID/CPU/PERIOD/CALLCHAIN 与参考一致;sideband 记录 COMM/FORK/EXIT/MMAP2/LOST;ioctl 集;/proc/sys/kernel/perf_event_paranoid 门(默认 2)。
  • 采样粒度(登记的分歧):软件采样骑 tick —— sample_period 低于一个 tick(100 Hz 下 10 ms)时聚合为 tick 率采样;参考实现的 per-event hrtimer swevent 为后续项。做热点概貌(秒级窗口)足够;做逐调用精确剖析不足 —— 用途边界如实。
  • 验证方式:以参考内核自身的 profiler 对本 ABI 构建,暴露合成测试未覆盖的对齐缺口(inherit 语义、环 fd O_RDWR、MISC cpumode 字节序),随后交付战役热点表(80,961 → 244,516 样本,内核 1-5 / 用户 2-16+ 帧链)—— ABI 验证以真实消费方为准。

用法

# guest 内(perf_event_paranoid=2 默认:同进程组计数 + 本用户采样)
# 计数模式:perf_event_open(attr.disabled=1, type=PERF_TYPE_SOFTWARE,
#   config=PERF_COUNT_SW_CPU_CLOCK) → ioctl ENABLE → 读 mmap 计数槽 → ioctl DISABLE
# 采样模式:attr.sample_period=N + mmap 环 → 读 PERF_RECORD_SAMPLE(IP, CALLCHAIN)
cat /proc/sys/kernel/perf_event_paranoid

§2syscost:启动普查采集器

  • 武装:内核 cmdline syscost=1;关闭时零成本(每次系统调用退出一次缓存原子载入;tick 钩子两次 relaxed 加)。不占用 dfx= 开关表 —— 本探针持自有 cmdline 键。
  • 计量内容:每原生系统调用号 {次数, 墙钟周期, 最大值}(NR_SLOTS=512)+ 慢操作环(>4 ms 异常值带调用方 comm,SLOW_RING=64 / SLOW_CYC=40000 tick)+ tick 模式 per-CPU user/kernel-task/idle 计数 + 256 槽内核文本页直方图(RIP_SLOTS=256,离线对照构建 ELF 的 nm 符号化);每 60 s 自定时器 softirq 转储(SYSCOST_DUMP_SECS=60)。
  • IF=0 EFLAGS 对探针(v3):边沿触发 + 自愈;每钩子读取真实 IF 标志并对模型裁决 —— 模型开启而实测 IF=1 判泄漏,闭合入 HEAL;HARDIRQ/SOFTIRQ/UART 区段分离;REST 调用点 #[track_caller] 归因 96 槽表;段带原始 TSC 戳。这是 IF=0 份额的官方测量(Tier-3),非代理。
  • 门禁读数(Tier-1,静默 syscost 启动):census TERM-DESCHED 8(允许范围 8±2)/ WAKE-REFUSED 32(允许范围 32±4);tick ≥99.5/s;零 panic/OOM;系统调用量按档位类别范围(debug 1550 万 ±80%,release 5000 万 ±60%);clock_gettime 3-4 µs;nanosleep ≤244 ms。

§3pbench:七组微基准

test/pbench.c:单一静态 musl x86_64 二进制,在 Rux 与同机参考内核上以同一二进制运行 —— 每个数字都是同二进制对。以 init 身份运行(init=/test/pbench)取静默探针启动。计时:逐操作 rdtsc 差值,以 CLOCK_MONOTONIC_RAW 校准;输出行 PBENCH <name> n=<N> med=<us> p99=<us> min=<us> max=<us> avg=<us> wall=<us>,终止行 PBENCH DONE rc=0;不支持的基元自动 SKIP。

组量什么协议要点
P1p1_null(SYS_getuid 循环 N=1e6)/ p1_clock空系统调用与时钟读取基线
P2p2_ctxsw1 字节管道乒乓钉于 CPU0/CPU1,N=1e5,取半程(单次切换)
P3p3a_fault_anon(64MB)/ p3b_fault_cow(32MB)/ p3c_fault_file(16MB)缺页三态
P4p4_fork_exit / p4_fork_exec(N=1e3)exec 目标为自身重执行
P5p5a_pipe / p5b_dgram+recv_peek / p5c_stream_write / p5e-p5f 流控判别74 B(hilogd 协议形态);p5a N=1e5,p5b N=2e4
P6p6_stat/openclose/getdents/read_cached/write_fsync/append/mkdrmdir/unlink1000 文件 × 4KB 树
P7p7_sleep1msnanosleep 1 ms ×1e4,记 OVERSHOOT

门禁锚列(pb1,KVM debug 类):p1_null 0.300 / p1_clock 0.371 / p2_ctxsw 1.242 / p3b_cow 8.075 / p6_write_fsync 8442.6 / p6_mkdrmdir 216.7 / p6_unlink 54.6 / p6_append 5.19 µs;Tier-2 判据 = 中位 ±20% 或改善。p2_ctxsw 锚已声明过期(pre-nohz 父版已 +60% 漂移,重新测量已记录在案)。

§4性能门禁:三层与守护域

合入门禁按三层执行(docs/development/perf-gate-baseline.md 为权威表;perf-gate.sh 自动化):

  • Tier 1(全部内核改动):一次静默 syscost 启动(KVM q35 smp2/4G,syscost=1,780 s)—— census 精确、tick 率、零 panic/OOM、调用量范围、逐操作均值范围。
  • Tier 2(触及热路径:mm/sched/fs/ipc/binder/timer/arch trap):加一次 pbench 启动,P1-P7 中位 ±20% 或改善;档位类规则:跨类比较无意义(debug 与 release-strong 不跨)。
  • Tier 3(分配器或 IRQ 路径改动):IF=0 份额(官方 EFLAGS 对测量,20.4 ±3pp)。
守护域关键行
分配/回收small_alloc 全局类锁区段每次启动 ≤2500 万;REST 占机 ≤10%;回收慢路径 drct=0 类
调度GRQ 平均持锁 1200–7320 ns;census 8±2/32±4;p2 ±20%;p4 fork 行开放回归挂账
文件系统stat/openclose/read_cached/append/mkdrmdir/unlink 中位带;buffer 命中率 ≥99.1%
中断/IRQIF=0 20.4±3pp;max cli REST ≤10 ms;SOFTIRQ 3.1±2pp;无新 IRQ-OFF 打印类
IPCp5a 18.3 / p5b 23–41 / p5c/f 24–27 / p5c3 25 / p5d 41–46 µs 带表
binderSLOW-TXN 类:queue ≤10 ms 全域;{1,64} exec 侧 4.5-9 s 键带;FAIL 判据 queue ≥50 ms
可比性铁律:对比两侧必须同加速器(KVM vs KVM);debug 与 release-strong 不跨类;TCG 下 p2 读数被宿主负载主导;基线更新仅经由自身过门的合并。

§5专项计数器

  • fsw(cmdline fsw=1):fs 同步写类普查 —— FSW1 行(br/rd/wr/sd/ev/sa/pb/ps/pc/ph/pb2/pm/lvl/es)+ FSW2 行(ri/wi/lk/ls/ni/ar/fr/j=jstart.jstop.jlazy.jcommit_fast.jrevoke/bl/biglock/w walks.hits.misses);每分钟 :30 转储(避开 syscost 的控制台发送竞争)。fs 域门禁读"无新同步写类出于供给阶段之外"。
  • mmprof / PageCacheOps:内存记账核对与页缓存命中率(meminfo 行),OOM 取证的输入。
  • census / wakewatch:调度停滞普查与唤醒→运行延迟,归调度域(见调度器 §8)。

§6标准工作流

  1. 发现:Tier-1 syscost 转储的逐操作均值出带 → 定位系统调用号或 census 类;
  2. 归因:pbench 定位组(P2 切换 / P5 IPC / P6 fs)→ syscost RIP 直方图或 REST 表定段 → trace 事件(如 rux:schedtrace、lock:)取微观序列;
  3. 修复验证:同 rig 交错 A/B(≥3 取中位)→ perf-gate.sh 三层判定 → 基线整表刷新随合并。

工具哲学:每一项门禁域在工具集中有对应测量;若某改动影响系统性能而现有工具测不到,为它新增 DFX 工具是改动的一部分,不是事后项(合并门政策)。全部新观测走 tracepoint(见tracepoint 框架)。
