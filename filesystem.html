文件系统

概述

Rux 内核实现了完整的文件系统支持，包括：

  • VFS (虚拟文件系统) - 统一的文件系统抽象层
  • Ext4 文件系统 - 完全兼容 Linux ext4 格式
  • Page Cache - 文件缓存机制
  • 文件描述符管理 - POSIX 兼容的 fd 管理

核心数据结构

Inode (索引节点)

pub struct Inode {
    pub ino: u64,           // inode 编号
    pub mode: u32,          // 文件类型和权限
    pub uid: u32,           // 用户 ID
    pub gid: u32,           // 组 ID
    pub size: u64,          // 文件大小
    pub blocks: u64,        // 块数量
    pub atime: u64,         // 访问时间
    pub mtime: u64,         // 修改时间
    pub ctime: u64,         // 状态改变时间
    pub nlink: u32,         // 硬链接数
    // ... 其他字段
}

Dentry (目录项)

pub struct Dentry {
    pub name: String,       // 文件名
    pub inode: Arc,  // 关联的 inode
    pub parent: Weak,// 父目录
    pub mounted: bool,      // 是否是挂载点
}

File (打开文件)

pub struct File {
    pub dentry: Arc,// 关联的目录项
    pub pos: AtomicU64,     // 当前位置
    pub flags: u32,         // 打开标志
    pub mode: u32,          // 访问模式
}

Extent 树

Ext4 使用 Extent 树来管理文件块映射，比 Ext3 的间接块映射更高效：

pub struct ExtentHeader {
    pub eh_magic: u16,      // 0xF30A
    pub eh_entries: u16,    // 条目数
    pub eh_max: u16,        // 最大条目数
    pub eh_depth: u16,      // 树深度
    pub eh_generation: u32, // 生成号
}

pub struct Extent {
    pub ee_block: u32,      // 逻辑块号
    pub ee_len: u16,        // 长度（块数）
    pub ee_start_hi: u16,   // 物理块号高16位
    pub ee_start_lo: u32,   // 物理块号低32位
}

特性 状态 描述

// 标准文件描述符

系统调用

系统调用 描述
open(path, flags, mode) 打开文件
close(fd) 关闭文件
read(fd, buf, count) 读取文件
write(fd, buf, count) 写入文件
lseek(fd, offset, whence) 设置文件位置
dup(oldfd) 复制文件描述符
dup2(oldfd, newfd) 复制到指定描述符
