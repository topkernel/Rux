内核配置(Kernel.toml)

编译期配置,零运行时开销 —— 对应仓库文档 docs/guides/configuration.md

§1配置如何生效

配置文件是仓库根的 Kernel.toml。构建时 build.rs 解析它并生成 kernel/src/config.rs,内核代码通过 use crate::config::* 使用生成的常量。

Kernel.toml  --build.rs-->  kernel/src/config.rs  --use-->  内核各模块
两条铁律:① kernel/src/config.rs 是生成产物,禁止手改;② 改完 Kernel.toml 会自动触发重编译,若不生效就 cargo clean 后重建。

§2查看与修改

make config        # 查看当前配置(等价 cat Kernel.toml)
make menuconfig    # TUI 交互配置(需 whiptail)

make menuconfig 提供 12 个配置大类:Memory / SMP / Scheduler / Network / Sub-features / Drivers / Boot / Debug / Performance / Security / View / Save。

§3常用配置段

段常用键说明
[platform]default_platform默认构建架构(如 "riscv64")
[memory]kernel_heap_size / physical_memory / page_size / user_stack_size内核堆、物理内存(MB)、页大小、用户栈(MB)
[smp]enable_smp / max_cpusSMP 开关与核数上限
[network]eth_mtu / tcp_socket_table_size网卡 MTU、TCP socket 表容量
[printk]ring_buffer_size / log_levelkmsg 环形缓冲与默认日志级别
[performance]opt_level / lto优化等级与 LTO
[mount] [filesystem] [process] [sync] [graphics]——其余段以 Kernel.toml 内注释为准
以仓库当前值为准:个别键的实际取值随阶段需求调整(例如内核堆大小曾为支撑大用户态负载而调大),本文只列键名与含义;文档示例默认值若与 Kernel.toml 冲突,以后者为准。

§4在内核代码中使用

use crate::config::*;

let heap = KERNEL_HEAP_SIZE;
let cpus = MAX_CPUS;
let mtu  = ETH_MTU;
// 常用:ENABLE_SMP, KERNEL_HEAP_SIZE, PAGE_SIZE,
//       USER_STACK_TOP, ENABLE_NETWORK, DEFAULT_TIME_SLICE_MS ...

核对生成结果:cat kernel/src/config.rs 或 grep "MAX_CPUS\|USER_STACK" kernel/src/config.rs。

§5常见错误

  • 构建报 Error: Configuration file parsing failed —— Kernel.toml 语法错误(TOML 格式、类型、缺引号),按 build.rs 指出的位置修复。
  • 改了配置但行为没变 —— 确认改的是 Kernel.toml 而不是生成文件;cargo clean && cargo build --package rux --features riscv64 强制重新生成。
  • make menuconfig 报缺 whiptail —— sudo apt-get install whiptail(RHEL 系:sudo yum install newt)。
