系统调用

概述

Rux 内核的系统调用完全对齐 Linux RISC-V 的系统调用号和 ABI，确保 Linux 二进制程序可以在 Rux 上直接运行。

核心原则

  • 使用与 Linux 相同的系统调用号
  • 使用与 Linux 相同的数据结构布局
  • 遵循 POSIX 标准的行为规范

调用约定

RISC-V 系统调用约定

寄存器 用途
a7 系统调用号
a0-a5 系统调用参数（最多6 个）
a0 返回值（或错误码）

用户态调用流程

// 用户态系统调用封装
static inline long syscall(long n, ...) {
    register long a7 __asm__("a7") = n;
    register long a0 __asm__("a0");
    // ... 设置 a0-a5

    __asm__ volatile("ecall"
                     : "+r"(a0)
                     : "r"(a7)
                     : "memory");

    return a0;
}

实现方式

系统调用分发

pub fn syscall_dispatch(syscall_num: usize, args: [usize; 6]) -> isize {
    match syscall_num {
        63 => sys_read(args[0], args[1] as *const u8, args[2]),
        64 => sys_write(args[0], args[1] as *const u8, args[2]),
        93 => sys_exit(args[0] as i32),
        172 => sys_getpid(),
        221 => sys_execve(args[0], args[1], args[2]),
        // ... 更多系统调用
        _ => {
            warn!("Unknown syscall: {}", syscall_num);
            -ENOSYS as isize
        }
    }
}
