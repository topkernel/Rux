MISSION 1 — WAKE-PLACEMENT RESERVATION: IMPLEMENTED (the 35A decision,
accepted). Commits d6124bbc + ccfc708e + 2beb2ded.

- Storage: the wakewatch side table (WwSlot gains a packed hint word
  (pick_pass_seq << 8) | (cpu + 1)) — no Task layout change, per that
  module's documented discipline. slot.task stays the validity key.
- Validity clock: per-CPU PICK_PASS_SEQ, bumped at the TOP of
  pick_next_task (always under the GRQ lock). A reservation is live
  until the hinted CPU's NEXT pick pass. This deliberately does NOT
  test the idle bitmap: the wake-side clear_idle already clears the
  bit BEFORE the hinted CPU runs its pass, so an idle-bit test would
  have a hole exactly covering the race. The seq transition and the
  pass's pick decision share one GRQ hold, so there is no interleaving
  window (unlike the idle-bit form).
- Stamp sites (both under the GRQ lock, both followed by a resched IPI
  to the stamped CPU): enqueue_task's find_idle_cpu tail (fork path —
  the nudge decision moved INSIDE the lock; IPI still sent outside),
  and wake_up_enqueue when the caller's IPI target (ti_cpu) is
  idle-marked (the Task::wake_up path — its select_task_rq prefers
  prev cpu, so the IPI'd CPU and ti_cpu coincide).
- Heal-path safety (ccfc708e): the stamp is gated on the wake being a
  real state transition (entry state sleeping/stopped). R56/R46/R49
  heal re-links reach the same tail but NO IPI follows them — a stamp
  there could reserve a task for a WFI CPU with no interrupt coming.
- Pick side: CFS pick_next_cpu skip reason 6, same bounded 32-entry
  stash as affinity/ownership; RT/DL picks override (counted as steal
  when live). The hinted CPU never skips its own reservation; an
  idle-marked CPU never sleeps with nr_running > 0 (R20-2), so a
  hinted task cannot strand.
- Census: hint=onor/steal/exp counters consumed at check_picked; the
  hinted CPU's own in-flight pass reads stamped_seq+1 (bump precedes
  the scan) and is attributed onor (2beb2ded — the first A/B boot
  showed onor=0 steal=0 exp=141, which was the misattribution).
  Heartbeat line extended (dfx=wwcensus-gated; serial-clean default).
  wresv=0 disables ONLY the skip — one image A/Bs the fix.
