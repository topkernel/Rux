§3登记的缺口与定性

  • F-6(posixaio):1/6 概率启动挂起 —— fdreap retire_complete 的 RCU 宽限永不过(monopolist-window 族);4 次定向复现 + 2 次重放未再捕获(1/6 保持);fio 子进程不可回收 T=150s + hung-task pid >120s + fdreap close 完成停滞刷屏为特征签名。
  • libaio:io_setup/io_submit 全 ENOSYS(UAPI 缺口,syscall/memory.rs);fio 干净退出 err=38 —— errno 纪律正确,属未实现而非错实现。
  • F-7(io_uring):setup 返回 fd、环形 mmap 由 io_uring_mmap_handler 供给,进入 enter 契约后用户态解引用 NULL+0x1e SIGSEGV(2× SIGDEATH + teardown #GP);内核存活 —— 环形语义不完整,登记为 io_uring 深化项。
  • F-8:numjobs 启动的收尾阶段观测到停靠 forker + KOT-KILL 级联(qsrun forker pid 306,128 KSIG9)—— fio 自身结果不受影响(rc=0、数据正确),移交调度线。

§4机位与扩展

  • 机位:x86_64 KVM q35 -cpu max smp2/2G,virtio-blk(run/rootfs-qa.img 私有 ext4 拷贝),dfx=taskdump,watchdog;每类负载一次独立启动,20 次启动;PID 1 = /test/qa/qsrun(cmds 协议:预算 + 程序行,QSRUN-BEGIN / RES|name|rc|tail / QS-ALL-DONE)。
  • fio 构建:静态 musl 3.36(libaio 引擎内建),源码 tar 包入 git,构建脚本 userspace/fio/build-x86.sh。
  • 扩展方式:userspace/ci/classes/ 追加 .cmds(行格式 <预算秒> fio --name=… --filename=/test/qa/<file>);跑批 INJBINS=run/fio-bin test/qrtests/run-suite-x86.sh -f "run/<class>.cmds"。

§52026-11-17 复测(当前 main debug 内核)

  • 负载类复测:48M 直写 / 48M 直读(20 s)/ 48M 直随机读写(15 s)/ 64M 缓冲写 —— 4/4 rc=0;此前 512M 直写 ENOSPC 系镜像剩余空间约束(~70M 可用),非内核缺陷,作业尺寸边界入档。
  • 延迟百分位采集未遂:JSON 经 dump 工具落盘后由 qsrun 捕获,但 RES 尾部截断只保留分布尾部 —— 百分位数据不可靠,不入册;全量 JSON 回采(镜像外 debugfs 提取或加大 tail 预算)列入补测队列。
  • 同宿主噪声声明:复测窗内同宿主运行其他 lane 的 QEMU;组级吞吐读数受其影响,本复测仅记录通过性与边界,吞吐结论仍以第 5/5b 轮为准。
