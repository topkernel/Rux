Roadmap and milestones

The boot-achievement timeline + current goals — authoritative source: docs/progress/roadmap.md

§1Current goals (2026-11)

  • A complete GNOME desktop loop (x86_64 + KVM primary): GDM login achieved; the gnome-session component chain (gsd → gnome-shell) closing out.
  • OpenHarmony launcher → desktop: /data mounting and the SystemUI lock screen achieved; advancing toward the full launcher home screen.
  • Maximizing the LTP pass rate: r27 = 1084/1869, attacking the FAIL/CRASH/TIMEOUT surface.
  • Aligning debugging with the reference kernel: the tracepoint framework expanding (lock/tcp/input families + PSI + log control); deep water: lockdep/RCU-stall/blktrace/perf-probes/kdump.

§2Milestone timeline

2026-09-29

Ubuntu 22.04 (riscv64) full userspace boots

A graphical desktop session (framebuffer + evdev), bash -i, both D-Bus buses, ptys, SysV IPC, 4-CPU SMP.

2026-10-07

x86_64 lands in main

Ubuntu 22.04 amd64 boots to a graphical desktop on q35; LTP x86 r3 = 850/1869 the same period.

2026-10-14

GNOME Shell renders

gnome-shell/mutter + Xorg-fbdev: the top bar, clock, workspace thumbnails, dash; 2,100 seconds zero panic.

2026-10-24

The OpenHarmony boot animation renders

bootanimation → render_service → composition → scanout — the whole OH graphics chain runs on Rux.

2026-10-27

Full GNOME Shell frame + closed input loop

Reproduced across three independent boots, zero panic; virtio-input IRQ-ified, typed characters echo in the focused terminal.

2026-10-28

Typed shell conversation verified pixel-exact

Two independent boots; convcheck adjudicates identical line geometry and cursor cells pixel for pixel.

2026-10-30

aarch64 lands in main

QEMU virt (cortex-a72) interactive root shell, signals, the suite 1119/1119 green; requires -M virt,gic-version=3.

2026-10-31

OpenHarmony /data mounted + SystemUI lock screen

After the ext4 superblock 32-bit checksum fix the stock userdata mounts; StartUser(100) in 64 ms; the lock screen renders every element (clock/date/status bar/unlock hint).

2026-11-01

The GDM greeter (x86_64 + KVM)

The stock chain end to end: udevd → logind (a real CreateSession fd) → gdm3 → PAM → gdm-x-session → gnome-session; 45 minutes zero panic; boot-to-login ~4.5 s. The same day x86_64+KVM becomes the standing test rig; the fs metadata family re-anchors (−65%~−88%).

2026-11-05/06

LTP r27 = 1084/1869; the munmap churn-race family closed

PI futexes land fully in main; the munmap chunked TLB-flush race family (taxonomy row 34) closes and ports back to all three architectures.

§3Beyond

  • Continuing LTP climbs (TIMEOUT-class cases get top priority);
  • observability deep water: lockdep-class, RCU-stall, blktrace, perf-probes, kdump;
  • closing the security gap register item by item (KASLR, text/rodata W^X, stack protectors);
  • LTP on aarch64; a btrfs evaluation.
