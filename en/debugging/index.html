Debugging

§2Kernel logging

  • The serial port is the primary log (console=ttyS0): everything prints to the UART during boot; after the scheduler starts the default level drops to emerg, and dmesg -n 7 reopens the full console output.
  • Levels 0–7 match the reference; the macros pr_emerg!/pr_err!/pr_warn!/pr_info!/pr_debug! (println! is a pr_info! alias); release builds compile out pr_debug.
  • The 1 MB kmsg ring: read via /proc/kmsg, syslog(2), dmesg; the devkmsg policy (/proc/sys/kernel/printk_devkmsg: on|ratelimit|off) only decides how much the CONSOLE shows — the ring always records everything (our alignment with the reference's devkmsg semantics).
  • Persistent log (default off): panic logs survive a reboot in /var/log/kmsg; after a crash, extract offline with debugfs (see memory forensics §8).

§3The trace system (summary)

All new observability goes through the unified tracepoints (the observability policy, 2026-11-02). Currently 69 events / 17 groups; the tracefs tree matches the reference file-for-file and byte-for-byte; disabled sites are one load+test+branch, enabled +13–19 ns/record, the image +0.18%. Full design and usage on Tracepoints.

§4The dfx= runtime switches (the frozen legacy surface, 49 entries)

The boot parameter is dfx=switch1,switch2; the authoritative table is the dfx_switch_table! in kernel/src/dfx/switches.rs (49 entries, frozen and not growing — new observability goes to tracepoints); debugfs mirrors the same table at /sys/kernel/debug/dfx/; most tokens have migrated into arming aliases of rux: events (the mapping on Tracepoints §4). Compile-time features (Cargo.toml)

cargo build --target riscv64gc-unknown-none-elf --features riscv64,dfx-lock-owner
# dfx-lock-owner: one atomic store per lock/unlock; deadlock warnings carry holder=<cpu> + REMOTE-BT stack capture

§5GDB and QEMU-level debugging

  • GDB: make debug (after make build; attaches to QEMU's gdbstub — breakpoints/single-step/memory).
  • Deterministic reproduction: THREAD=single make run (single-threaded TCG); or ACCEL=tcg to disable KVM.
  • The QEMU monitor: attach via a unix socket, screendump, register/memory dumps (hunt-wedge uses this automatically).
  • Serial to file: -serial file:xxx.log for offline grepping after long soaks.
