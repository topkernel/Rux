§2Layering and unsafe governance

docs/architecture/kernel-layers.md defines the longest-prefix-match layering: unmatched files default into the safest bucket.

  • Framework layer (arch/mm primitives/interrupt/virtio core/trace/perf): unsafe allowed, every block requiring a // SAFETY: comment (3,207/5,009 = 64% covered).
  • Service layer: targets 100% forbid(unsafe_code) — 47 files already forbid it at compile time, 56 more contain none; the first named shrink target syscall/io.rs went 69 unsafe tokens → 0 (typed entries + uaccess_safe).
  • The syscall boundary is the capsule boundary: entries validate and translate user pointers; uaccess_safe.rs provides typed copy_in/copy_out.
  • 12.9% of lines are unsafe; the trace module bans unsafe entirely.

The probe-tarball policy: guest test-case sources are archived only as userspace/probes/probes.tar.gz + extract.sh; make user / make test restore them idempotently via scripts/extract-probes.sh — loose guest C sources are never committed.

§4Language composition

The kernel itself is 100% Rust (no_std, plus the necessary platform assembly); userspace probes are C (musl cross-compiled); repository language statistics use the git ls-files basis (vendored toybox is marked linguist-vendored).
