Design · tenets

The ABI is the contract; the internals are a clean-room design

Externally: syscall numbers and semantics, ELF/auxv, futex, the procfs layout — down to the uname strings glibc's loader keys on — all match Linux. Internally: free of historical baggage, better designs in Rust — every internal divergence is registered with compatibility evidence.

📜Compatibility as the constitution

POSIX and the Linux kernel ABI are the supreme constraints: LTP families pass family by family; distribution userspace runs unmodified.

Modules · map

What the kernel is made of

Every subsystem has its own design page with mechanisms, data structures and measured numbers. Summary below.

🧮Scheduler

A single global run queue (GRQ): for the 2–4 vCPU target it eliminates load balancing and task stealing entirely; wakeup paths go direct.

hold ~2.8µs · census 8/32 in band
Design →

🧠Memory management

Buddy allocator + magazine small-object allocation, global page cache, per-task VMAs; the munmap churn-race family fully closed.

class-lock sections 19.7M/boot · gate ≤25M

💾File systems

ext4 (rw) + async batched block reads + buffer-cache hit-rate protection; pbench filesystem medians all in band.

buffer cache hit rate 99.1%

📡IPC & binder

A complete OpenHarmony-compatible binder, unix sockets, pipes, SysV IPC; the cross-process deadlock family fixed and regressed.

Quickstart

Three commands

A Linux host + QEMU is all you need. Full requirements, toolchains and troubleshooting in Getting started.

①Clone

git clone https://github.com/topkernel/Rux
cd Rux

A pure Rust workspace — no submodules, no vendored dependency images.

②Build

make build                 # riscv64 (default)
make build PLATFORM=x86_64 # x86_64

Kernel.toml is compiled into kernel/src/config.rs at build time.

③Run

make run        # musl minimal rootfs → shell
make ubuntu-run # Ubuntu 22.04 → GNOME desktop

The serial port (ttyS0) is the primary log; GUI images boot with -snapshot so the shared image is never written.
