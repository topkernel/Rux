# docs/development/pass3-pair-exceptions.txt — recorded pair-gate exceptions
#
# `scripts/refactor/pass2.py pair` verifies that the compiled kernel is
# unchanged apart from symbol names. Pass 3 (seed-core-design.md §2c.5) is
# a REWRITE, not a move: an inline unsafe block becomes a contract-carrying
# function in the subsystem's unsafe.rs, and even though every wrapper is
# #[inline(always)] (so no out-of-line copy is emitted and no call is
# added), DEBUG-build instruction selection for the inlined body drifts by
# a few instructions. Release builds (opt-level 3) inline identically —
# those are pinned by the pbench gate, not this file.
#
# Each pattern below is passed to `pair --allow-unpaired REGEX` (repeatable).
# The stage-b runner greps this file; a pattern with no matching unpaired
# symbol is reported by pair as unused (harmless). Adding a pattern here is
# a visible, reviewed edit — same policy as unsafe-verification-exemptions.tsv.
#
